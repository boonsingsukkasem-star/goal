# นโยบายความเป็นส่วนตัวของ Goal

เวอร์ชันเนื้อหา: 2026-08-17

สถานะ: พร้อมส่งตรวจทางกฎหมาย แต่ยังห้ามเผยแพร่ production จนกว่าจะได้รับข้อมูลจริงและหลักฐานการตรวจตามหัวข้อ
“Production publication gate”

หน้า public canonical: `https://goal.co.th/privacy`

## ผู้ควบคุมข้อมูลส่วนบุคคล

- ชื่อนิติบุคคล: `<LEGAL_ENTITY_NAME>`
- เลขทะเบียน (ถ้ามี): `<LEGAL_ENTITY_REGISTRATION_NUMBER>`
- ที่อยู่จดทะเบียน: `<LEGAL_ENTITY_ADDRESS>`
- วันที่นโยบายมีผล: `<LEGAL_PRIVACY_EFFECTIVE_DATE>`
- วันที่ที่ปรึกษากฎหมายตรวจ: `<LEGAL_PRIVACY_REVIEW_DATE>`
- จุดติดต่อด้านความเป็นส่วนตัว: `privacy@goal.co.th`
- ฝ่ายช่วยเหลือ: `support@goal.co.th`

ค่าเหล่านี้ถูกอ่านจาก Vercel Web environment variables และแสดงบนหน้า `/privacy` โดยตรง Production
build จะ fail หากชื่อนิติบุคคล ที่อยู่ วันที่มีผล หรือวันที่ตรวจทางกฎหมายยังว่าง เพื่อไม่ให้เผยแพร่นโยบายที่มี
ข้อมูลผู้ควบคุมไม่สมบูรณ์

## ขอบเขต

นโยบายนี้ใช้กับเว็บไซต์ `goal.co.th`, แอป Goal บน iOS/Android และ Goal API

Goal เก็บข้อมูลต่อไปนี้เท่าที่จำเป็น:

- ข้อมูลบัญชี เช่น อีเมล ชื่อที่แสดง และรหัสอ้างอิงจาก Google, Facebook หรือ Apple
- ทีม ลีก นักเตะ การแข่งขัน รายการโปรด การติดตาม และการตั้งค่าการแจ้งเตือน
- ข้อมูลอุปกรณ์ เช่น Expo push token ภาษา เขตเวลา เวอร์ชันแอป และระบบปฏิบัติการ
- Session cookies บนเว็บและ session data ใน OS-backed secure storage บน mobile
- ข้อมูลการใช้งานที่จำเป็นต่อ personalization ความปลอดภัย ป้องกัน abuse และแก้ไขปัญหา
- การเปิดข่าวแบบไม่ซ้ำและ engagement signal เพื่อจัดอันดับข่าว
- ข้อมูลที่ใช้เรียก AI และผลลัพธ์ เฉพาะเมื่อผู้ใช้เรียกฟีเจอร์ดังกล่าว
- ข้อมูลที่ผู้ใช้ส่งให้ฝ่ายช่วยเหลือและบันทึกการดำเนินการตามคำขอ

Goal ไม่ขายข้อมูลส่วนบุคคลและไม่ใช้ข้อมูลบัญชีหรือข้อความแจ้งเตือนเพื่อโฆษณาข้ามบริการ

## แหล่งข้อมูล

Goal ได้ข้อมูลจากผู้ใช้โดยตรง จากอุปกรณ์ จากผู้ให้บริการเข้าสู่ระบบ จากการทำงานของบริการตามปกติ
และจากผู้ให้บริการข้อมูลฟุตบอล/แหล่งข่าวสาธารณะ

## วัตถุประสงค์และฐานการประมวลผล

| วัตถุประสงค์                                                   | ฐานการประมวลผล                                          |
| -------------------------------------------------------------- | ------------------------------------------------------- |
| บัญชี รายการโปรด การติดตาม personalization และฟีเจอร์ที่ร้องขอ | จำเป็นเพื่อให้บริการตามข้อตกลงกับผู้ใช้                 |
| Push notification และความสามารถที่ต้องขอ permission            | ความยินยอม ซึ่งถอนผ่านการตั้งค่าระบบหรือแอปได้          |
| ความปลอดภัย ป้องกัน abuse แก้ข้อผิดพลาด และปรับปรุงความเสถียร  | ประโยชน์โดยชอบด้วยกฎหมาย โดยต้องประเมินผลกระทบต่อผู้ใช้ |
| ตอบคำขอทางกฎหมาย เก็บหลักฐาน และปฏิบัติตามข้อบังคับ            | หน้าที่ตามกฎหมายหรือการก่อตั้ง/ใช้/ต่อสู้สิทธิเรียกร้อง |

การถอนความยินยอมไม่กระทบการประมวลผลที่ชอบด้วยกฎหมายก่อนหน้า

## ผู้ประมวลผลและการส่งข้อมูล

| ผู้ให้บริการ            | หน้าที่                                                                  |
| ----------------------- | ------------------------------------------------------------------------ |
| Supabase                | ฐานข้อมูล การยืนยันตัวตน Realtime และพื้นที่จัดเก็บ                      |
| Vercel                  | โฮสติ้ง API/Web, Runtime Cache, Queues, Cron และ operational logs        |
| Expo                    | สร้าง/อัปเดตแอป และส่ง push notification ผ่าน APNs/FCM                   |
| OpenAI                  | ประมวลผล AI football companion และสร้างข่าวสรุปโดยใช้ข้อมูลเท่าที่จำเป็น |
| Google, Facebook, Apple | เข้าสู่ระบบ เชื่อมบัญชี และเพิกถอน token ตามที่รองรับ                    |
| API-Football              | ข้อมูลการแข่งขัน ลีก ทีม นักเตะ และสถิติฟุตบอล                           |

ผู้ให้บริการบางรายประมวลผลข้อมูลนอกประเทศไทย ต้องมีการตรวจ Data Processing Agreement, ประเทศที่
ประมวลผล, subprocessor และมาตรการส่งข้อมูลข้ามแดนก่อน legal approval ลิงก์ข่าวภายนอกอาจทำให้เว็บไซต์
ปลายทางได้รับข้อมูลตาม browser เช่น IP address และอยู่ภายใต้นโยบายของเว็บไซต์นั้น

## AI และข่าว

AI ใช้ข้อมูลการแข่งขัน ทีม นักเตะ และคำขอที่จำเป็นเพื่อสร้างคำอธิบาย เปรียบเทียบ หรือสรุป ระบบตั้งค่า
OpenAI application requests เป็น `store: false` และไม่ส่งรายการผู้ใช้ที่ติดตามไปค้นข่าว คำตอบ AI อาจ
คลาดเคลื่อนและไม่ควรใช้เป็นคำแนะนำด้านการพนันหรือการเงิน

ข่าวแสดงหัวข้อ สรุป และลิงก์อ้างอิงไปยังแหล่งต้นทาง Goal ไม่จัดเก็บหรือเผยแพร่บทความเต็ม และอาจแก้ไข
หรือถอนสรุปเมื่อแหล่งข่าวแก้ไขข้อเท็จจริง

## ระยะเวลาเก็บรักษา

ใช้ตาราง canonical ใน `docs/legal/retention-and-deletion.md` โดยสรุป:

- บัญชีและโปรไฟล์: ตลอดอายุบัญชี; ลบจากระบบหลักภายใน 7 วันหลังยืนยันคำขอ
- รายการโปรด การติดตาม และ preference: ตลอดอายุบัญชีและลบพร้อมบัญชี
- Push token: จน logout/token ใช้ไม่ได้/ลบบัญชี; purge ภายใน 30 วัน
- Notification history: 30 วัน
- Personalization events: ไม่เกิน 180 วัน
- AI application records: 30 วัน
- News engagement signals: 90 วัน
- Operational logs: 90 วัน โดยลดข้อมูลระบุตัวบุคคล
- Security/audit events: 180 วันและ pseudonymize เมื่อทำได้
- Support requests: 24 เดือนหลังปิดเรื่อง เว้นแต่มีข้อพิพาท
- Encrypted backups: หมดอายุตามรอบภายใน 30 วัน

การระงับทางกฎหมายอาจทำให้ต้องเก็บข้อมูลบางส่วนเท่าที่จำเป็นและนานเท่าที่กฎหมายกำหนด

## สิทธิของผู้ใช้

ภายใต้เงื่อนไขของกฎหมาย ผู้ใช้อาจขอเข้าถึง รับสำเนา แก้ไข โอน คัดค้าน จำกัดการใช้ ลบข้อมูล หรือถอน
ความยินยอม ส่งคำขอจากอีเมลของบัญชีไปที่ `privacy@goal.co.th` Goal อาจขอข้อมูลเพิ่มเติมเพื่อยืนยันตัวตน
แต่จะไม่ขอรหัสผ่าน OTP หรือ access token

การลบบัญชีทำได้จากหน้า Account ใน Web/iOS/Android หรือจาก public page
`https://goal.co.th/account-deletion` แม้ผู้ใช้ถอนการติดตั้งแอปแล้ว

## ความปลอดภัยและเด็ก

Goal ใช้การควบคุมสิทธิ์ RLS การเข้ารหัสระหว่างส่ง การแยก environment การจำกัด secrets และการบันทึก
เหตุการณ์ ไม่มีระบบใดรับประกันความปลอดภัยได้ทั้งหมด บริการไม่ได้ออกแบบสำหรับเด็กและไม่ตั้งใจเก็บข้อมูล
เด็กโดยรู้ตัว ผู้ปกครองสามารถขอให้ตรวจสอบและลบได้

## การเปลี่ยนแปลงและร้องเรียน

เมื่อแก้สาระสำคัญ Goal จะอัปเดตเวอร์ชันและวันที่มีผลบนหน้า public และแจ้งเพิ่มเติมผ่านแอปหรืออีเมลเมื่อ
กฎหมายกำหนด หากคำขอไม่ได้รับการแก้ไขตามสิทธิ ผู้ใช้สามารถร้องเรียนต่อสำนักงานคณะกรรมการคุ้มครองข้อมูล
ส่วนบุคคลหรือหน่วยงานกำกับที่มีอำนาจได้

## Production publication gate

ก่อนตั้ง `NEXT_PUBLIC_APP_ENV=prod` ต้อง:

1. ใส่ค่าจริงของผู้ควบคุมข้อมูลและวันที่มีผลครบ
2. ตรวจรายชื่อ processor/subprocessor, ประเทศ, DPA และ cross-border safeguards
3. ตรวจ lawful bases, retention, user rights, minors position และ notification consent กับพฤติกรรมจริง
4. ให้ที่ปรึกษากฎหมายไทยตรวจและบันทึกวันที่ใน `LEGAL_PRIVACY_REVIEW_DATE`
5. เก็บหลักฐาน version ที่อนุมัติและผู้อนุมัติในระบบเอกสารของนิติบุคคล
6. ตรวจให้ App Store Privacy และ Google Play Data safety ตรงกับนโยบายฉบับเดียวกัน
